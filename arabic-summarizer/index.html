Quick Start

ابدأ الاستخدام في 3 خطوات:

curl -X POST https://fofo-apis-vercel.vercel.app/api/summarize \
  -H "Content-Type: application/json" \
  -d '{
    "text": "النص العربي اللي تبي تلخصه هنا..."
  }'

Response:

{
  "summary": "الملخص المختصر للنص...",
  "original_length": 1500,
  "summary_length": 150,
  "compression_ratio": "90%"
}
